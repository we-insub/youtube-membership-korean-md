# 유튜브 멤버십 한국어 마크다운 지침

## 활용 방법

1. **쓰는 글의 분야를 고릅니다.** 위 표에서 가장 가까운 문서를 하나 고릅니다.
2. **AI에 맡길 때는 두 파일을 함께 첨부합니다.** 공통 지침(「한국어-웹문구-작성지침.md」)과 해당 분야 파일을 같이 넣으면, 분야 문서의 예문과 조건이 함께 적용됩니다.
3. **한 화면에 성격이 다른 글이 섞이면 나눠서 고릅니다.** 콘서트 예매 페이지라면 가수 소개는 연예, 마지막 결제 버튼은 웹·앱 문서가 더 가깝습니다.
4. **확인해야 하는 값은 원문에서 봅니다.** 운영 시간, 출연 회차, 제도 적용 대상, 요금·통계처럼 시점에 따라 달라지는 내용은 게시 시점의 원문 자료에서 확인합니다.

AI에 붙여 넣을 때는 이렇게 요청할 수 있습니다.

```text
첨부한 「한국어-웹문구-작성지침.md」와 「분야별/쇼핑-상품.md」를 지침으로 삼아
아래 상품 상세 페이지 문구를 다듬어 주세요.
원래 뜻과 말투는 살리고, 고칠 이유가 있는 부분만 고쳐 주세요.
바꾼 곳은 무엇을 왜 바꿨는지 한 줄씩 붙여 주세요.

[여기에 다듬을 문구]
```
